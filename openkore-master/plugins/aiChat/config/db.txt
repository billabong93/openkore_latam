# Base de conhecimento simples sobre classes e niveis.

[requirements]
O nivel minimo para a primeira classe é job 10.
O nivel minimo para troca/evolucao/quest da segunda classe é job 40, e o maximo é job 50.
O nivel necessario para reborn/rebirth/renascimento é base 99 e job 50.
O nivel necessario para terceira classe é base 99 e job 70.

[general]
Há duas raças disponíveis para o player, Humano e Doram.
A única classe disponível para Dorans é Summoner, todas as demais são para a raça Humanos.
A cidade onde acontece o reborn/rebirth/renascimento é Juno.
Apenas evoluções de classes principais renascem (Swordsman (Espadachim), Mage (Mago), Archer (Arqueiro), Acolyte (Acolito), Thief (Gatuno) e Merchant (Mercador)).
As classes expandidas são Taekwon (Taekwon), Ninja (Ninja), Gunslinger (Justiceiro) e Summoner (Invocador).
O aprendiz inicia no navio naufragado.
