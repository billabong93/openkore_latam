# Base de conhecimento simples sobre classes e niveis.

[requirements]
O nivel minimo para a primeira classe (incluindo classes expandidas) é job 10.
O nivel minimo para troca/evolucao/quest da segunda classe (classes principais 2-1/2-2) é job 40, e o maximo é job 50.
O nivel necessario para reborn/rebirth/renascimento é base 99 e job 50 (classe 2).
O nivel necessario para terceira classe (classes principais) é base 99 e job 70 (transclasse).
O nivel necessario para evolucao de Taekwon (Taekwon) é job 40 (para Taekwon Master/Mestre Taekwon ou Soul Linker/Espiritualista).
O nivel necessario para evolucao de Ninja é base 99 e job 70 (para Kagerou ou Oboro).
O nivel necessario para evolucao de Gunslinger (Justiceiro) é base 99 e job 70 (para Rebel/Insurgente).

[general]
Há duas raças disponíveis para o player, Humano e Doram.
A única classe disponível para Dorans é Summoner (Invocador), todas as demais são para a raça Humanos.
A cidade onde acontece o reborn/rebirth/renascimento é Juno.
Classes expandidas não renascem (não viram transclasse).
Apenas evoluções de classes principais renascem (Swordsman (Espadachim), Mage (Mago), Archer (Arqueiro), Acolyte (Acolito), Thief (Gatuno) e Merchant (Mercador)).
As classes expandidas humanas são Taekwon (Taekwon), Ninja (Ninja) e Gunslinger (Justiceiro).
Evoluções expandidas (LATAM): Taekwon Master (Mestre Taekwon), Soul Linker (Espiritualista), Kagerou (Kagerou), Oboro (Oboro), Rebel (Rebel)/Insurgente (Insurgente).
Bard (Bardo) e suas evoluções são masculinas; Dancer (Odalisca) e suas evoluções são femininas.
Kagerou é masculino e Oboro é feminino.
O aprendiz inicia no navio naufragado.
